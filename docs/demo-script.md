# 五分钟答辩演示

## 主路径

1. 用 30 秒展示首页、商品目录和真实价格来源字段。
2. 进入 DIY，依次选择 CPU、显卡、主板、内存、SSD、散热、电源、机箱。
3. 展示六项兼容性检查、功耗、电源冗余和显卡空间；说明 3DMark 是对比估算而非实测。
4. 选择带 GLB 的机箱，旋转视角并展示八大件节点的显隐和高亮。
5. 加入购物车，检查 DIY 快照，登录后下单并使用沙箱支付。
6. 切换管理员账号，展示订单、商品价格来源和 Storage 上传入口。

## 技术亮点

- Vue 3 + FastAPI + PostgreSQL 完整业务闭环。
- 有来源的价格历史，不使用伪造趋势。
- Supabase 只承担托管数据库和对象存储，Secret Key 不进入浏览器。
- GLB 节点合同、降级模型和 DIY 订单快照。

## 备用路径

- Supabase 不可用：使用本地 PostgreSQL，图片与模型展示现有兜底资源。
- GLB 加载失败：查看器自动显示程序模型，并保留完整配置功能。
- 外部行情不可用：明确显示“暂无可靠历史价格”，不影响下单演示。
