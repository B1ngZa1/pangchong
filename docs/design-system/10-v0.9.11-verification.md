# v0.9.11 设计系统验收记录

日期：2026-09-06 · 维护对象：PANGCHONG Vue 3 电商前端

## 本轮增量

- 修复生成产物漂移：`tokens.css`、`public/design-system.tokens.css`、`tailwind-theme.js` 与 DTCG 唯一源重新一致。
- 新增 `design:figma` / `design:figma:check`，生成 179 Token 的 Figma handoff manifest：175 个变量、4 个 Effect Style、35 个组件入口；补齐 `DsEmptyState`、`DsMenu` 与 `DsPriceSummary` 映射。
- 将按钮/图标按钮 spinner 与 Skeleton shimmer 的固定时长与匀速 easing 迁移为 `motion.duration.loading/shimmer` + `motion.ease.linear`，并纳入 reduced-motion 生成覆盖。
- 将 Commerce Navigation 与 Build Summary 从“规范已定义”推进为可运行组件，并补齐导航语义与配置事实契约测试。
- 将 AppNavbar 的桌面、移动与 mega menu 当前路由统一暴露为 `aria-current="page"`，并以路由测试锁定视觉高亮与辅助技术语义一致。
- 将设计 lint 扩展为递归组件扫描，并拒绝组件层写死 animation/transition 时长，确保新增动效只能消费 `motion.*` Token。
- `design:figma` 现在递归校验所有 `src/design-system/components/**/*.vue` 都有 handoff 映射，漏项会让生成与检查直接失败。
- 购物车摘要中的自提点、配送选项、门店位置和常见问题入口均改为真实路由，并由 `cart-navigation.test.js` 防止死按钮回归。
- 将 AppNavbar 的搜索/mega menu 颜色与动效迁移到 semantic Token，并加入全局 `prefers-reduced-motion` 降级规则。
- 将 Commerce Media Card、Workbench Shell、Parts Inspector 从“建议 Vue 化”推进为可运行组件，并补齐 layout/density Token 与契约测试。
- manifest 显式记录 `Default` / `High Contrast` mode、Figma scope、WEB code syntax、组件源码路径和当前同步权限边界。
- 将 Apple、IBM Carbon、Vercel Geist 的可迁移规则落到 Token、组件契约和 Figma 执行顺序中。
- 将 AppNavbar 移动端菜单补齐 `aria-expanded` / `aria-controls`、打开后焦点进入、Tab 焦点圈定、Escape 关闭和触发器回焦，并由 `navbar-navigation.test.js` 锁定交互契约。
- 将 `DsAsyncState` 的 loading 根节点补齐 `aria-busy="true"`，并在 settled 状态移除该属性；错误态改为 `role="alert"` + `aria-live="assertive"`，由设计系统契约测试锁定异步进行中与错误播报边界。
- 将购物车数量步进器的当前值标记为 `aria-live="polite"` + `aria-atomic="true"`，确保增减结果可被辅助技术感知。
- 将用户下拉菜单抽取为 `DsMenu`，统一触发器关系、Arrow/Home/End 导航、Tab 离开前关闭、Escape 回焦和外部点击关闭，并由 `design-system-menu.test.js` 锁定组件契约。
- 将购物车价格明细抽取为 `DsPriceSummary`，并让 `DsOrderSummary` 复用同一价格事实组件，支持购物车隐藏重复主总价。
- 将首页、服务中心、全局页面过渡和遗留 Tailwind 按钮/卡片的写死 duration 迁移到 `motion.duration.micro/normal/slow/prominent/ambient/spin`，并纳入 reduced-motion 覆盖。
