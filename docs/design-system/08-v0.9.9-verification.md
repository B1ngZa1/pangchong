## 本轮设计决策

- 组件层统一消费 semantic Token；购物车全选使用原生 `DsCheckbox`，支持 `checked / mixed / unchecked`。
- 3D 配置器使用 `DsToggle`、`DsIconButton` 和明确的 `aria-pressed`，并尊重 `prefers-reduced-motion`。
- 应用壳层新增 skip link、可聚焦的 `main` 锚点、标题滚动留白和 `color-scheme` 声明。
- 3D 查看器的界面层颜色已迁移到 Tailwind/semantic Token；Three.js 场景材质色保留为业务渲染数据。

## 外部模式对照

- [Vercel Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)：语义结构、可见焦点、减少动态效果、避免 `transition-all`。
- [IBM Carbon Text input accessibility](https://carbondesignsystem.com/components/text-input/accessibility/)：原生键盘行为、标签关联、辅助文本和错误播报。
- [Atlassian Design Components](https://atlassian.design/components/)：组件契约、状态变体和业务组件抽象方式。
