# PANGCHONG 界面文案规范

这份规范约束商城、DIY、门店、服务页和后台中面向使用者的文字。目标是让用户在扫描页面时先理解当前状态、下一步操作和会影响决策的信息。

## 语气与层级

- 使用简洁、克制的中文。标题说明页面目的；正文说明用户能完成什么；按钮从动作开始，例如“查看配置”“去结算”“重新同步”。
- 面向用户的装饰性英文一律改为中文。品牌 `PANGCHONG`、产品型号、CPU、GPU、GLB、WebGL、DIY 等行业术语保留，并在首次出现时配合中文语境。
- 先给事实，再给建议。价格、库存、兼容性、运输和模型来源不得用模糊的营销语替代。
- 无数据、加载、失败和回退状态要明确发生了什么、当前仍可做什么以及下一步操作。不要把工程错误原文直接展示给用户。

## 页面文案结构

| 位置 | 写法 | 示例 |
| --- | --- | --- |
| 页眉辅助标题 | 2–8 个字，说明当前阶段 | `准备下一次升级` |
| 页面标题 | 名词或明确目标 | `DIY 装机配置器` |
| 描述 | 一句交代能力或范围 | `实时核对兼容性、功耗、机箱空间与价格走势。` |
| 主操作 | 动词开头，描述结果 | `去结算` |
| 错误状态 | 事实 + 可执行恢复动作 | `购物车暂时无法加载` / `重新同步` |
| 3D 提示 | 说明预览边界，不替代交易信息 | `配置、核价与交易仍以清单为准。` |

## 维护流程

1. 直接修改 Vue 源文件中的可见文本，不在运行时拼接或覆盖翻译。
2. 运行 `npm run copy:extract`，更新文案清单。
3. 运行 `npm run copy:check`，确认清单与源代码一致。
4. 为新增流程补齐加载、空状态、失败和成功反馈；用键盘和窄屏检查不会截断关键动作。
