## 负责解决的架构问题

| 架构问题 | 解决方案 | 完成标志 |
| --- | --- | --- |
| 本地通过但合并后失效 | CI 统一运行检查并保护主分支 | PR 无绿色门禁不能合并 |
| 生产与开发配置混用 | staging/production 配置分离，启动期强校验 | 默认密钥、seed、reload 在生产被拒绝 |
| 缺少可观测性 | 请求 ID、结构化日志、错误追踪、交易/备份告警 | 故障注入可触发并送达告警 |
| 有备份但不可恢复 | 明确 RPO/RTO，隔离环境定期恢复 | 恢复报告包含版本、耗时和校验 |
| 发布不可回滚 | 版本化制品、健康检查、观察窗口和回滚 runbook | 演练能恢复到上一可用版本 |
| 风险文档与代码脱节 | PR 模板强制任务/风险/方案/证据；同 PR 更新登记表 | 风险状态可追溯到提交和验收人 |
