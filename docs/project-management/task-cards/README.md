每天 17:30 前，成员在自己的任务卡或项目看板更新：完成内容、次日目标、阻塞、关联风险、提交/PR 和验收证据。每个阶段最后一天由任务卡指定的非作者验收人正式验收。

## 状态与证据

- `未开始`：尚未产生可评审产物。
- `进行中`：已有分支/PR，且下一步和预计完成时间明确。
- `待验收`：完成定义全部满足，已提交证据。
- `已完成`：非作者验收通过。
- `阻塞`：外部输入或关键依赖缺失；必须关联风险 ID。

没有 CI、测试、截图、日志、数据抽检或演练记录等证据时，不得标为 `已完成`。
