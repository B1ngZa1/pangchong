# 发布检查清单

> 状态：执行模板，不代表任何项目已经通过  
> 使用方式：每次 staging/production 发布复制一份带日期和版本的记录，由非作者复验

## 1. 版本与质量

- [ ] 发布 commit/tag、负责人、变更范围和回滚版本已记录。
- [ ] `scripts/quality-check.ps1` 或 `scripts/quality-check.sh` 通过。
- [ ] 前端类型检查、测试、生产构建通过。
- [ ] 后端 compileall、pytest、Alembic 单一 head 通过。
- [ ] Secret、依赖、SAST 和容器镜像扫描无未接受的高危问题。

## 2. 配置与数据

- [ ] 使用 `.env.production.example` 生成未跟踪的生产配置，所有占位值已替换。
- [ ] `python scripts/verify_production_config.py` 通过且输出不包含凭据。
- [ ] 生产不挂载 demo seed，不存在公开测试账号和本地弱凭据。
- [ ] 空库迁移、已有数据升级和回滚/前滚方案已验证。
- [ ] PostgreSQL 与对象存储备份完成，恢复演练在有效期内。

## 3. 网络与安全

- [ ] 正式域名、HTTPS、证书链、自动续期和 HTTP 跳转通过。
- [ ] 只对公网开放 80/443；22 仅受控来源；3000/8000/5432/6379 不公网开放。
- [ ] CORS、Host、CSP、安全响应头、生产 API 文档访问策略通过。
- [ ] 登录、刷新、支付、上传和管理员接口限流通过。
- [ ] refresh token 安全 Cookie、CSRF、撤销/轮换和日志脱敏通过。
- [ ] 详细项目已按[网络与安全基线](../architecture/network-security.md)复验。

## 4. 交易与第三方

- [ ] 服务端订单价格、库存并发和重复提交验证通过。
- [ ] 支付宝商户沙箱/生产联调、RSA2 验签、金额/商户校验、幂等、对账和退款验证通过。
- [ ] 支付篡改、重复/乱序回调、超时重试和第三方不可用测试通过。
- [ ] 邮件、物流、价格服务和 Storage 均设置超时、受控重试、告警和降级。
- [ ] 正式环境不返回模拟支付、模拟物流或伪造成功结果。

## 5. 可观测性与上线

- [ ] 健康检查、结构化日志、request id、核心指标和告警已验证。
- [ ] 支付失败率、下单失败率、5xx、延迟、数据库连接、磁盘/存储容量有告警。
- [ ] 灰度/维护窗口、值班人、业务验收人和回滚决策人已确认。
- [ ] 发布后完成首页、登录、购物车、下单、支付沙箱/小额真实交易、管理员和资产访问 smoke test。
- [ ] 观察窗口结束后记录结果；异常时按回滚阈值执行，不边修边赌。
