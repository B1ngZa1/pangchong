# 旧版静态网站页面结构

> 状态：已归档。本文描述的是被 Vue 电商应用替代的早期静态页面，仅保留作历史参考；当前入口见 [项目 README](../../README.md)。

> 胖虫官网前端页面的完整目录与模块说明

## 文件组成

| 文件 | 说明 | 大小 |
| --- | --- | --- |
| `index.html` | 首页（产品展示、DIY定制介绍、社区） | ~27KB |
| `products.html` | 产品列表页（全部产品筛选浏览） | ~15KB |
| `diy.html` | DIY在线装机页（141款配件自由搭配） | ~20KB |
| `about.html` | 核心技术页（品牌故事、六大优势） | ~18KB |
| `style.css` | 雷蛇风格暗黑主题样式 | ~30KB |
| `script.js` | 交互逻辑 + 产品/配件数据库 | ~45KB |

## 交互功能

| 功能 | 说明 |
| --- | --- |
| 全局搜索 | 顶部搜索按钮，实时匹配产品名/配置/系列 |
| 产品筛选 | 6个分类标签一键过滤 |
| 快速预览 | 悬停卡片点击查看完整详情 |
| 购物车 | 侧边栏弹出，增删改数量、合计、结算 |
| 在线装机 | 8大配件自由搭配，实时计算总价和功耗 |
| 快速方案 | 5个预设一键加载装机配置 |
| Mega菜单 | 悬停"全部产品"展开4列分类导航 |
| 粒子动画 | 英雄区背景连线粒子效果 |
| 数字滚动 | 统计数字入场时动态递增 |
| 滚动动画 | 产品/功能卡片滚动入场淡入 |
| Toast提示 | 加入购物车后绿色弹窗反馈 |
| ESC关闭 | 按ESC关闭搜索/购物车/预览弹窗 |
| 响应式 | 适配手机/平板/桌面三端 |
