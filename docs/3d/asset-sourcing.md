# 3D 资产选型与验收

商城中的 3D 资产既是产品信息的一部分，也是需要公开分发的文件。选择素材时先验证许可，再处理视觉效果和文件体积。

## 选型顺序

1. **自制或书面授权的硬件模型**：用于机箱、显卡和完整 DIY 装配预览。记录授权主体、合同或邮件凭据、资产版本和导出日期。
2. **许可明确的开放资产**：用于灯光、材质、桌面环境等非品牌商品细节。Poly Haven 的素材均以 CC0 发布，可用于商业项目和再分发；它适合环境 HDRI、材质与通用场景物件，不应冒充具体硬件产品。
3. **技术回归样本**：Khronos 的 glTF Sample Assets 用于验证 GLB 加载、贴图和渲染特性。每个示例都应单独读取其许可；它们不是商品目录资产，也不应出现在商品页的商业展示中。

不要把厂商官网的图片、商品页、CAD 下载页或第三方预览链接当作再分发许可。没有明确许可时，只能用于内部参考，不能上传到公开素材库。

## 许可记录

后台绑定 GLB 时填写下面四项；前两项分别映射到现有的“素材许可”和“素材来源 URL”字段：

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| 素材许可 | `自制资产；公开分发已获授权` 或 `CC BY 4.0，作者姓名` | 说明公开分发依据 |
| 来源 URL | 可访问的授权页、资产页或内部授权记录编号 | 允许复核来源 |
| 作者与修改 | 作者、修改内容、导出日期 | CC BY 资产的署名与变更记录 |
| 资产版本 | `diy-case-v1 / 2026-09-16` | 让商品绑定可追溯 |

CC BY 4.0 允许商业使用、复制和再分发，但需要给出适当署名、许可证链接和修改说明。CC0 资产虽无需署名，仍应保存来源 URL 与下载日期，避免来源页面变更后无法复核。

## 交付验收

- 使用 GLB 2.0；DIY 机箱必须包含 `case`、`motherboard`、`cpu`、`gpu`、`ram`、`ssd`、`cooler`、`psu` 八个节点。
- 单文件建议不超过 6 MB，上传硬限制为 20 MB；删除隐藏面、螺纹和重复网格，贴图最长边不超过 2048。
- 贴图、网格和许可文件必须一起检查：模型可以加载不等于可公开使用。
- 在桌面与手机上各验证一次：可旋转、缩放、加载失败可显示“交互式示意预览”，而配置清单继续可用。

## 已核验参考

- [Poly Haven License](https://polyhaven.com/license)：站点说明其模型、HDRI 与贴图使用 CC0，并允许商业使用和再分发。
- [Creative Commons BY 4.0](https://creativecommons.org/licenses/by/4.0/)：商用再利用需要署名、许可证链接和修改说明。
- [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)：用于验证 glTF 功能；仓库按模型提供许可信息。
