# 架构文档

本目录描述当前代码的真实边界以及生产目标。适用读者为前端、后端、测试、运维和安全负责人。

## 阅读顺序

1. [系统总览](system-overview.md)：组件、调用链、信任边界和环境差异。
2. [前端架构](frontend.md)：页面、状态、API、3D 与浏览器安全边界。
3. [后端架构](backend.md)：路由、服务、数据访问、事务和第三方集成边界。
4. [网络与安全](network-security.md)：端口、域名、TLS、认证、支付回调和上线门禁。
5. [数据与存储](data-and-storage.md)：PostgreSQL、Redis、迁移、种子数据与资产存储。

## 状态标记

| 标记 | 含义 |
| --- | --- |
| 已实现 | 当前仓库已有实现，仍需通过对应测试和环境验证 |
| 部分实现 | 已有基础能力，但不能按生产能力对外承诺 |
| 目标 | 推荐的演进方向，当前代码不一定具备 |
| 阻断项 | 未完成前不能进入生产或真实交易 |

架构变更需要同步更新本文档、[发布检查清单](../operations/release-checklist.md)以及受影响的部署说明。
